# js-todo

Next.js で作ったシンプルな ToDo リストアプリです。

## 機能

- タスクの追加・編集・完了マーク・削除
- 期限の設定（今日まで／期限切れを色で表示）
- 画面上部に「今日まで」「期限切れ」の未完了タスク数を表示
- 「すべて／未完了／完了／期限切れ」での絞り込み
- カレンダーで日付を選び、その日が期限のタスクだけを表示
- 追加・削除時の通知
- データはブラウザの `localStorage` に保存されるため、ブラウザを閉じても残ります

## 起動方法

```bash
npm install
npm run dev
```

http://localhost:3000 を開いてください。
